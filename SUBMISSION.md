# 100-word submission summary

Autonomous ML Experimenter is a model-agnostic platform that runs bounded research loops, learns from prior trials, and converts evidence into governed model decisions. This prototype demonstrates the framework on Retailrocket-style interaction data using popularity, co-visitation, and implicit ALS recommenders. Optuna adapts search, MLflow records nested lineage, and Vertex AI produces schema-validated hypotheses and grounded summaries. Leakage-safe temporal evaluation separates validation, final testing, and monitoring replay. A human approval gate protects champion promotion, while Streamlit presents research trajectories, comparisons, registry state, drift, latency, and clearly labeled simulated incidents through compact, reproducible artifacts, ready for transparent review and practical production scaling discussions.
